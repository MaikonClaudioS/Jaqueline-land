# Jaqueline Alves | Landing Page

Projeto React + Vite organizado em componentes.

## Executar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Onde editar

- `src/config.js`: nome, WhatsApp, cidade, Instagram, textos, peças, depoimentos e fotos.
- `src/components/`: componentes visuais reutilizáveis.
- `src/styles/`: estilos separados por responsabilidade.
- `public/fotos/`: adicione aqui as fotos dos produtos e da galeria.

Para usar uma foto, coloque o arquivo em `public/fotos/` e informe somente o nome do arquivo no campo correspondente de `src/config.js`, por exemplo: `brinco1.jpg`.

A imagem principal usa `public/logo.jpeg` enquanto `fotoHero` estiver vazia.
